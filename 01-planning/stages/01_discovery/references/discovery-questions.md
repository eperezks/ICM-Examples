# Discovery questions

Answer each from the request. If the request does not say, it goes in Open questions. Skip none silently.

1. What problem is being solved, and how is it handled today?
2. Who has this problem? Name the user or persona.
3. What does success look like for them? How would we measure it?
4. What is explicitly out of scope?
5. What must be true for us to call it done? (becomes acceptance criteria)
6. What deadline, dependency, or commitment shapes this?
7. What could make this wrong, unwanted, or unsafe? (privacy, security, accessibility, abuse)
8. What existing behavior or data does this change?
